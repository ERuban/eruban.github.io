# eruban.github.io

Root of `eruban.github.io`: `robots.txt` (points crawlers to the project sitemaps), search engine
verification files and a redirect to [K5K1 Prog](https://eruban.github.io/k5k1prog-mac/).
Project sites are served from their own repositories, e.g. `/k5k1prog-mac/` from
[ERuban/k5k1prog-mac](https://github.com/ERuban/k5k1prog-mac) (`docs/`).
